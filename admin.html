eBay's file upload needs your photos as public web links. Signing in lets the app keep them in a public repository in your own GitHub account (no password goes through this app; the app asks GitHub for permission to write to your public repositories, and you can revoke that any time at github.com/settings/applications). Each car's photos can be removed again once eBay has fetched them.
